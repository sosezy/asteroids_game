## Описание проекта

Программа представляет собой двумерную аркадную игру «Астероиды», разработанную на языке Python с использованием библиотеки `pygame`. Игрок управляет космическим кораблём на тороидальном игровом поле, уклоняется от вращающихся астероидов и уничтожает их ракетами, набирая очки. В проекте реализованы тайловая анимация взрывов и смены состояния двигателя корабля, динамический полупрозрачный фон, русскоязычный интерфейс и объектно-ориентированная архитектура.

## Функциональные возможности

### Основной функционал
- Управление кораблём с клавиатуры: вращение вокруг центра, ускорение по вектору ориентации и стрельба ракетами из носовой части.
- Тайловая смена спрайта корабля при включении и выключении маршевого двигателя.
- Двухслойный фон: неподвижный космос с туманностями и полупрозрачный динамический слой мелких астероидов, движущийся влево с постоянной скоростью.
- Тороидальная геометрия игрового поля с сохранением линейной и угловой скоростей при пересечении границ.
- Инерция и сопротивление среды: плавное замедление корабля до полной остановки при выключенных двигателях.
- Периодическая генерация астероидов со случайными линейной и угловой скоростями (астероиды свободно проходят друг поверх друга).
- Ракеты с ограниченным временем жизни, рассчитанным так, чтобы снаряд не мог пролететь поле целиком даже по малой стороне.
- 24-кадровая тайловая анимация взрыва при столкновении ракеты или корабля с астероидом.
- Система жизней (начальное значение — 3), подсчёт очков (начальное значение — 0), возрождение корабля в центре и возврат к заставке после окончания игры.
- Запуск игры строго по щелчку мыши внутри прямоугольника заставки (клики вне заставки игнорируются).

### Дополнительный функционал
- Гибридная система графики: автоматическая загрузка пользовательских спрайтов из `assets/` или процедурная генерация всех тайл-листов при их отсутствии.
- Безопасная зона спавна астероидов (исключает появление астероида прямо поверх корабля).
- Контрастные полупрозрачные панели HUD с визуальными индикаторами оставшихся жизней.
- Соответствие кода стандартам PEP 8 и PEP 257, вынесение всех игровых параметров в отдельный конфигурационный модуль.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone [https://github.com/](https://github.com/)<ваш-логин>/asteroids-game.git
cd asteroids-game
```

### 2. Создание и активация виртуального окружения

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление
| Действие | Клавиша / кнопка |
|---|---|
| Запуск игры | Клик ЛКМ по прямоугольнику заставки |
| Вращение корабля влево / вправо | Стрелка влево / Стрелка вправо |
| Включение двигателя (ускорение) | Стрелка вверх |
| Выстрел ракетой | Пробел (`Space`) |

## Структура проекта

```text
asteroids_game/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── venv/
└── src/
    ├── __init__.py
    ├── config.py
    ├── sprites.py
    ├── entities.py
    └── game.py
```

**Назначение основных модулей:**
- `main.py` — точка входа в программу, создание и запуск главного цикла игры.
- `src/config.py` — все глобальные параметры и константы игры (размеры окна, скорости, физика, таймеры, цвета интерфейса).
- `src/sprites.py` — нарезка горизонтальных тайл-листов (`slice_tile_sheet`), загрузка или процедурная генерация графических ресурсов.
- `src/entities.py` — ООП-иерархия игровых объектов (`GameObject`, `Ship`, `Asteroid`, `Missile`, `Explosion`), тороидальная физика и проверка столкновений.
- `src/game.py` — класс `AsteroidsGame`, отвечающий за игровой цикл, обработку событий, генерацию астероидов, коллизии, HUD и отрисовку кадров.

## Пример использования

### Запуск программы
```bash
python main.py
```

### Сценарий работы в приложении
1. После запуска открывается окно «Астероиды» (960x640): отображаются неподвижный космический фон, движущийся влево полупрозрачный слой астероидов, заставка по центру и панели с показателями «Жизни: 3» и «Очки: 0».
2. Щелчок мышью вне заставки игнорируется; щелчок внутри прямоугольника заставки запускает игру и помещает корабль в центр поля.
3. Удерживайте стрелки влево/вправо для разворота корабля, стрелку вверх — для ускорения (спрайт корабля сменяется на тайл с работающим двигателем), нажимайте `Space` для стрельбы ракетами.
4. При попадании ракеты в астероид проигрывается тайловая анимация взрыва, а счётчик очков увеличивается на 1.
5. При столкновении корабля с астероидом астероид взрывается, количество жизней уменьшается на 1, а корабль возрождается неподвижным в центре.
6. Когда количество жизней доходит до 0, все объекты скрываются, на экран возвращается заставка, а итоговые значения жизней и очков остаются видимыми до нового старта.
